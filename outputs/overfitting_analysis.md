## 二、曲线背离现象

以 `bilstm_lr1e-3_do0.5` 为典型:训练损失从 0.49 一路降到 0.018(训练准确率 99%+),
而验证损失从 epoch 3 的 0.31 反弹到 epoch 9 的 0.49 —— **训练/验证损失曲线明显背离**,
即经典过拟合形态。所有随机初始化词向量的 run 均在最佳 epoch 后 3 轮内触发早停,
说明早停(patience=3)+ 恢复最佳权重有效地把模型固定在背离发生前。

注意力模型 `attn_lr1e-4_do0.3` 背离最严重(末轮 lossgap +0.536,训练准确率 99.4%):
注意力层额外引入打分网络参数,且能对训练样本形成"记忆性"对齐,过拟合倾向更强。

## 三、超参对过拟合的影响

1. **学习率**:lr=1e-3 时收敛极快但最佳 epoch 出现极早(第 2~7 轮),之后立即过拟合;
   lr=1e-4 收敛慢而稳,最佳 epoch 推迟到 12,验证准确率也最高(0.8981)。
2. **Dropout**:0.5 相比 0.3 略降过拟合(lossgap 更小),但在本数据上收益有限,
   lr 的作用远大于 dropout。
3. **预训练词向量**:对过拟合的缓解最显著。冻结版 gap@best 仅 +0.022、
   末轮 lossgap 仅 +0.085 —— 词向量不参与更新,可训练参数大幅减少;
   微调版在保持低 gap(+0.058)的同时取得全场最高 val/test 指标,
   说明预训练先验既提升泛化又抑制过拟合。

## 四、结论与改进方向

- 早停 + 最佳权重恢复是本项目最有效的防过拟合手段,所有 run 都在背离恶化前停止;
- 预训练词向量微调 = 精度与抗过拟合的最优组合(test_f1 0.9022);
- 若进一步调优,可尝试:weight decay(L2 正则)、更大 dropout 作用于 LSTM 输出、
  数据增强(同义替换)、减小 maxlen 或对长评论分段,以继续压低 lossgap。
