# 过拟合分析(基于各实验真实训练历史 `outputs/*_history.json`)

> 数据来源:每次训练记录的逐 epoch 训练/验证 loss 与准确率,全部为真实训练产出。
> 本版为【语料去重 + 停用词修正(剔除否定/程度词)+ 否定词合并 + OOV 等量级/组合式
> 初始化】定稿管线下 14 组实验的结果(数据无训练/测试文本重叠)。
> 说明:`gap@best` = 最佳 epoch 处 训练准确率 − 验证准确率;
> `lg@best` = 最佳 epoch 处 验证损失 − 训练损失;`末轮lg` = 停止时两者的差。

## 二、曲线背离现象

随机初始化词向量组普遍呈现典型背离:训练准确率 3~4 轮即接近 99%+,
验证损失却持续上行(末轮 lossgap +0.42~+0.65,如 `bilstm_lr1e-3_do0.5`
训练损失趋 0 而验证损失累计涨幅超过 0.4)。去重后训练集少了约 1700 条
"重复记忆点",模型可背的样本变少,背离出现得更早也更陡,所有 run 都在
背离恶化前 3 轮内被早停截停并回滚最佳权重。

注意力 + 随机词向量的 `attn_lr1e-4_do0.5` 背离最重(gap@best +0.140、
末轮 lossgap +0.655):注意力打分网络的额外容量对训练样本形成"记忆性"对齐。

预训练词向量组显著抑制背离:冻结版 gap@best 仅 +0.003、末轮 lossgap +0.031
(几乎无过拟合);微调组 gap 也普遍 <0.05。

## 三、超参对过拟合的影响

1. **学习率**:随机词向量组 1e-3/5e-4 最佳 epoch 出现在第 3~4 轮,之后立即过拟合;
   1e-4 训练更久(gap 略大但验证更稳)。微调组相反:lr=5e-4 下词向量快速适配,
   3 轮即达最佳且 gap 最小(+0.037),同时取得全场最高 test_F1 0.9022。
2. **hidden 容量(h64/128/256 对比)**:h=64 欠拟合最轻也最抗过拟合
   (gap +0.055、末轮 lg +0.233,但 val/test 最低);h=256 容量最大
   (末轮 lg +0.386);h=128 居中。容量与泛化的权衡清晰。
3. **Dropout**:注意力模型上 0.5 反而更过拟合(attn do0.5 训练了 19 轮,
   gap +0.140)——随机初始化下注意力需要更多轮次收敛,拖长了可过拟合窗口;
   基础模型上 0.3 与 0.5 差异不大。
4. **预训练词向量**:仍是抗过拟合最有效的手段(先验好、可训练量少),
   且"等量级 OOV 初始化 + 否定词组合式初始化 + 微调 lr=5e-4"组合
   在低 gap 下同时拿到最高精度。

## 四、结论与改进方向

- 早停 + 最佳权重恢复把每个 run 都固定在背离发生前,是最有效防线;
- 预训练词向量微调(尤其 lr=5e-4)= 精度与抗过拟合的最优组合;
- 进一步可尝试:weight decay、数据增强(同义替换)、更大规模预训练词向量
  (覆盖"不满意"等合并词以减少 OOV)、对抗训练。
